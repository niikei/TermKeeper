# CLI仕様

## tk add

用途:

未整理用語を登録する。

例:

```text
tk add ICMR
```

処理:

1. Meaning検索
2. 未解決Inbox検索
3. 必要に応じてInbox登録

## tk inbox

用途:

未処理一覧表示

例:

```text
tk inbox
```

## tk resolve

用途:

InboxをMeaningへ変換

例:

```text
tk resolve 1
```

## tk search

用途:

用語検索

例:

```text
tk search MDM
```

## tk show

用途:

Meaning詳細表示

例:

```text
tk show 100
```

## tk discard

用途:

Inbox破棄

例:

```text
tk discard 10
```
