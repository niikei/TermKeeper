# TermKeeper

## 概要

TermKeeper は、業務中に出てきた「知らない言葉」を捨てずに蓄積するためのCLIツールである。

目的は用語集を作ることではない。

目的は、

- 知らない言葉を捕捉する
- 後で整理する
- 必要なときに再参照できる

状態を実現することである。

## 背景

会議やチャットでは短時間に大量の用語が登場する。

例:

```text
MDM
ICMR
BTP
TCR
BOM
```

その場で調査する余裕がないため、

```text
知らない
↓
忘れる
```

が発生しやすい。

TermKeeperはこの問題を解決する。

## 設計思想

### 会議中は登録だけ

ユーザーが会議中に行う操作は最小限とする。

例:

```text
tk add ICMR
```

### 整理は後で行う

登録時に正式名称や説明を求めない。

後で整理できればよい。

### 意味中心で管理する

このシステムは略語管理システムではない。

管理対象は意味(Meaning)である。

例:

```text
MDM
Master Data Management
マスタ管理
```

は同じMeaningを指す。

同じ表記でも製品・業務領域が異なれば別Meaningになり得るため、SAPなどのscopeを
概念の境界として記録する。文字列一致だけで遭遇をMeaningへ自動分類しない。

## 成功条件

成功条件は正しい用語集が完成することではない。

成功条件は、

```text
知らない言葉を記録する習慣が定着する
```

ことである。
